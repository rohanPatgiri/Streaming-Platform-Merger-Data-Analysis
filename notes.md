## Workflow of a Data Analysis Project


### Defining the Problem Statement/ Scope of the Project clearly

- First step is to be clear about what is the scope of this project
- What are youe expected outcome at the end of this process


### Collecting the Data, Cleaning it , Pre Processing and initial EDA of the Data

- Search and collect relevant data that will help you get the end result
- Prepare the data in a suitable format for the analysis phase by converting it into the appropriate format, cleaning it etc.


### Analysis Phase

- Analyze the Datasets and derive insights from it.
- How?
    - By Calculating Statistical Measures
    - By Calculating Relevant Metrics
    - By visualizing the data

### Report And Dashboard

- Prepare the Insights derived from the analysis phase in a structured and presentable manner in a report for the stakeholders
- Present the data in a visually in the form of a dashboard
- (Optional) Include Actionable Recommendations based on the insights.

### Presentation
- Prsent the findings/ insights to the stakeholders. (A cosensed form of teh Report)

### Making decisions based on the Insights (for Decsion Makers : Managers, Executives etc.)

- Use the insights to make informed decisions
